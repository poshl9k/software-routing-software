# Резервная копия мастер-портала

`vs-master-backup.timer` ежедневно запускает `vs_master.backup` от пользователя `vs-master-web`. Копирование SQLite через online backup API согласовано с WAL; перед публикацией проверяется `PRAGMA integrity_check`, затем временный файл атомарно переименовывается. Каталог `/var/lib/vs-router/master/backups` имеет режим `0700`, файлы — `0600`; сохраняются семь последних копий. При ошибке существующие копии не удаляются. Отсутствующая или неинициализированная база не заменяется пустым файлом.

**Граница защиты:** это только локальные копии на том же VPS. Нет зашифрованной передачи на ноды, станцию либо в Telegram и нет гарантии восстановления после потери VPS. База содержит персональные данные; не публиковать и не прикладывать к тикетам. Ключ `VS_ROUTER_SECRET_KEY` хранится отдельно в `/etc/vs-router/master.env` и **не входит** в SQLite-копию; без него сохранённые токены нельзя расшифровать. Его резервирование и проверка восстановления требуют отдельного защищённого канала и явного операционного решения.

Для проверки восстановления используйте отдельную изолированную машину/каталог, скопируйте туда один backup и отдельно восстановите ключ; выполните `PRAGMA integrity_check`, миграции и вход в тестовый мастер без доступа к рабочим нодам. Не заменяйте действующую базу на работающем сервере и не запускайте два мастера с одним bridge-токеном.
