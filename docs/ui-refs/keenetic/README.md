# Reference: веб-интерфейс Keenetic (KeeneticOS web configurator)

Референсы аналогичных разделов Keenetic web UI + зафиксированная UX/UI-логика, чтобы
перенести её на панель `vs-router`. Код не менялся: это материалы для следующего шага.

## Из чего состоит

| Файл | Содержание | Скриншотов |
| --- | --- | --- |
| `00-KEENETIC-UX-LOGIC.md` | **Сводка**: 13 сквозных UX/UI-паттернов Keenetic + «что не копировать» | — |
| `01-ui-shell-and-overview.md` | Оболочка (меню, шапка, поиск, язык, мастер) + Статус/Системный монитор/Монитор трафика | 12 |
| `02-internet-connections.md` | Интернет: Ethernet/PPPoE/L2TP/WISP/mobile, VLAN, MTU, MAC, приоритеты подключений, резерв, расписания | 27 |
| `03-home-network-dhcp.md` | IP/DHCP домашней сети, время аренды, регистрация устройств, карточка клиента | 14 |

Каждый раздел построен по общему шаблону: навигация → структура экранов → UX/UI-логика →
элементы управления → состояния → список скриншотов → «что переносим в vs-router» → источники.

## Источник

Официальная документация Keenetic: `https://support.keenetic.ru/eaeu/ultra/kn-1811/ru/<id>-<slug>.html`
(модель Ultra KN-1811, KeeneticOS 5.x). Все 128 цитируемых статей проверены — HTTP 200/301,
404 нет. Полный TOC (513 статей) — `keenetic-toc.txt`.

Скриншоты — реальные PNG из этих статей: `https://support.keenetic.ru/eaeu/asset/images/<uuid>-ru.png`.
Всего 190 файлов в `screenshots/`, каждый упомянут в соответствующем документе (сверено 1:1).
**В git они не попадают** (чужой материал + воспроизводимы): см.
`screenshots/.gitignore`. Коммитится только письменный разбор со ссылками на статьи.

## Как добывался материал

- Статья: `https://support.keenetic.ru/eaeu/ultra/kn-1811/ru/<slug>` (slug включает числовой id).
- Скриншоты в статье — `src="../../../asset/images/<uuid>[-ru].png"`; абсолютный адрес:
  `https://support.keenetic.ru/eaeu/asset/images/<uuid>-ru.png`.
- Текст статьи — снятие тегов из HTML; картинки осмотрены через vision.

## Служебные файлы

- `_AGENT-SPEC.md` — спека, по которой собирались референсы (шаблон и правила).
- `specs/*.txt` — задания на каждый блок (7 параллельных агентов).
- `keenetic-toc.txt` — оглавление документации Keenetic (slug | название), 513 статей.

## Ограничения

- Модель Ultra KN-1811; у других моделей состав меню и доступные компоненты отличаются —
  Keenetic это прямо оговаривает.
- Описания выведены из текста статей и скриншотов. Где источник не показывал деталь
  (подписи кнопок в обрезанных формах, тексты ошибок, поле поиска по клиентам), это явно
  помечено как неподтверждённое — см. раздел «Что НЕ копировать» в `00-KEENETIC-UX-LOGIC.md`.
- Живой веб-конфигуратор роутера не поднимался (нужен реальный Keenetic); источники —
  официальная документация и её скриншоты.
