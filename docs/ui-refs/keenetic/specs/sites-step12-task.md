## Что сделать

Редактор сайта/DDNS сейчас рисуется резидентной `Card` прямо в потоке страницы. Перенеси его
в модальное окно, по образцу уже сделанного туннеля:

- `Dialog` (`fullWidth`, `maxWidth="md"`, `open` по выбранному элементу) → `DialogTitle`
  (`Сайт: <имя>` / `DDNS: <имя>`, справа — существующий `DeleteButton` с тем же per-row label)
  → `DialogContent` c `FormGrid`, разбитым на секции (`PageSection`) → `EditorFooter` в конце.
- Секции для **сайта**: `Идентификация` (имя), `Подключение` (hostname, upstream,
  WAN-адрес), `Сертификат` (режим + поля `manual`-сертификата/ключа или `dns01`-токен —
  существующие `SecretField`).
- Секции для **DDNS**: `Идентификация` (имя), `Подключение` (провайдер, hostname,
  WAN-интерфейс), `Секрет` (API token / TSIG key).
- Кнопки создания (`+ Добавить сайт`, `+ Добавить домен`) и импорт продолжают открывать окно
  для созданного элемента (как сейчас раскрывают редактор).
- При закрытом окне страница = только таблица списка (никаких форм в потоке).

Никаких функциональных изменений: `summary` для списка, `empty`-фабрики новых строк, `valid`,
`form`, `addLabel`, импорт `.conf` (туннели), `rowActions`, пояснение `<p className="sub">`
про статус DDNS — по смыслу как есть.
