## Проблема

Один туннель разложен по ПЯТИ вкладкам (`Общие / Подключение / Ключи / Пиры / Дополнительно`)
и правится резидентной карточкой прямо в потоке страницы. По §9 это два нарушения: свойства
одного объекта разбиты вкладками, и редактор живёт на странице, а не в отдельном окне.

## Что сделать

### 1. Редактор туннеля — модальное окно

- Клик `Открыть` на карточке туннеля (и создание нового туннеля, и импорт `.conf`, которые
  сейчас тоже раскрывают редактор) открывает **модальный `Dialog`**:
  `Dialog` (`fullWidth`/`maxWidth="md"`, `open` по выбранному туннелю) → `DialogTitle`
  (`Туннель: <имя> · WireGuard|AmneziaWG · Сервер|Клиент`) → `DialogContent` с формой →
  существующий `EditorFooter` в конце формы.
- Убери `PageTabs` внутри редактора туннеля и состояние `tab` для него (верхние вкладки
  страницы не трогать).
- Страница при закрытом окне = только список карточек туннелей.

### 2. Одна форма с секциями внутри окна

Секции заголовками (`PageSection`), порядок:

1. **Идентификация** — read-only то, что задано при создании и не меняется: `Имя`,
   `Протокол`, `Роль` (роль после создания неизменна — `CONTEXT.md`), `Интерфейс`,
   `Публичный ключ` (как сейчас, без расшифровки).
2. **Подключение** — `Listen port` (сервер) / `Endpoint` (клиент), `AllowedIPs`,
   `Keepalive`, `Открыть порт на WAN` — те же контролы и та же валидация.
3. **Ключи** — существующий блок генерации/приватного ключа + `InfoNote` про повторную
   генерацию, который уже есть.
4. **Пиры** (только сервер) — существующие карточки пиров со всеми полями, `QR-код`,
   `Сгенерировать PSK`, `DeleteButton`, `+ Добавить пира` и `EmptyState` «Пиров нет.».
   Это по-прежнему список внутри формы — это законно (§9 запрещает вкладки для полей
   одного объекта, а не вложенные списки).
5. **Дополнительно** — `ExpertDisclosure`: параметры обфускации AmneziaWG (Jc, S1, S2, H1–H4),
   маршрут/автоадрес, прочие второстепенные контролы — всё, что сейчас на вкладке
   «Дополнительно», без изменения поведения.

### 3. Сохранить поведение целиком

`useDraftEditor`-поток, `editor.begin/setValue/save/cancel`, keygen-вызовы, `peerAutoAddress`,
`showQr`, импорт `.conf` с превью, валютность/валидаторы, «Роль после создания не меняется»,
`<p className="sub">` пояснения — по смыслу без изменений.
