## Что сделать

Каждый редактор элемента списка — модальное окно (`Dialog` + `DialogTitle` с именем объекта
и `DeleteButton`, где удаление сейчас в редакторе; `DialogContent` с `FormGrid` и секциями
`PageSection`; в конце существующий `EditorFooter`). Секции:

- **Подсеть DHCP** — `Идентификация` (имя/подсеть, read-only то, что задано при создании),
  `Диапазон` (пул), `Параметры` (шлюз, DNS, время аренды), `Резервирования` (существующий
  вложенный список — это законно).
- **Резервирование** — `Идентификация` (имя, MAC), `Адрес` (IP).
- **Upstream DNS** — `Идентификация` (адрес/имя), `Транспорт` (UDP/DoT/DoH + порт/путь).
- **DNS-правило** — `Условие` (домен/набор), `Решение` (upstream/блокировка).

Списки и вкладки страницы `/dhcp` и `/dns` (разные списки: аренды / подсети;
журнал запросов и т.д.) остаются как есть — это законные вкладки. При закрытом окне страница
содержит только список: резидентированной формы в потоке быть не должно.

Никаких функциональных изменений: фабрики новых строк, `valid`, `save`-маппер, `summary`,
`fmtRemaining` и любые честные состояния — по смыслу как есть.
