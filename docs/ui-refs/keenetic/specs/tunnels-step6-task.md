## Что именно сделать (три пункта)

### 1. Факты в карточке туннеля — списком, а не абзацами

Сейчас read-only карточка туннеля печатает факты двумя абзацами:
`<p>Интерфейс: wg-office</p>` и `<p>Клиентов: 2</p>` / `<p>Endpoint: …</p>`.
Это выбивается из ритма панели: остальные read-only факты идут списком
`<dl className="kv"><dt>…</dt><dd>…</dd></dl>` (см. «Режим и доступ» в DNS).

Замени оба абзаца на один `kv`-список с теми же подписями и теми же значениями:
`Интерфейс` → имя интерфейса; для сервера — `Клиентов` → число; для клиента —
`Endpoint` → `tunnel.endpoint ?? "не задан"`. Ничего нового не добавляй: только форма подачи.
Badge «Черновик» и `InlineStatus` со статусом службы остаются на месте, в том же порядке.

### 2. Сервер без клиентов говорит об этом словами

Сейчас при нуле пиров карточка показывает `Клиентов: 0` — число вместо ответа. Keenetic на
пустой список отвечает явным текстом. Сделай так:
- если у серверного туннеля `peers.length === 0`, в строке `Клиентов` покажи
  `нет клиентов` (вместо `0`);
- если пиры есть — как было, числом.

### 3. Вкладка «Пиры» без пиров — пустое состояние

На вкладке пиров серверного туннеля (`tab === 3`) сейчас при пустом списке нет ни одного
сообщения — только форма и кнопка добавления пира. Добавь перед списком (`t.peers.length === 0`)
`EmptyState` с текстом `Пиров нет.` и больше ничем: кнопку добавления пира не дублировать и
не переносить, вторых сообщений рядом не добавлять.

## Проверка (обязательно, своими глазами)

Подними стенд сам (он погашен):
```
cd /tmp/krefs && PEERS=1 SERVICES_RUNNING=1 node stub-api.mjs &   # сервер с 2 пирами + клиент с endpoint
cd frontend && npm run dev &
```
Переменные stub: `PEERS=1` (у сервера 2 пира), без неё — сервер без пиров (проверка п. 2),
`TUNNELS_EMPTY=1` (пусто, проверка «Туннелей пока нет»).
Скриншотер: `node /tmp/krefs/shot.mjs <url> <out.png> [текст кнопки] [ширина] [высота]`
(кликает кнопку по точному тексту; вкладки — тоже кнопки, можно кликнуть «Пиры»).

Посмотри через `vision_analyze` три состояния `http://127.0.0.1:5173/tunnels`:
1. `PEERS=1` — карточки сервера (2 клиента) и клиента (endpoint) с kv-списком;
2. без `PEERS` — сервер показывает `нет клиентов`; открой карточку («Открыть»), вкладку «Пиры» —
   видно `Пиров нет.`;
3. `TUNNELS_EMPTY=1` — `Туннелей пока нет`.
Приложи к отчёту, что именно ты увидел, а не «выглядит хорошо». Стенд после проверки погаси.
