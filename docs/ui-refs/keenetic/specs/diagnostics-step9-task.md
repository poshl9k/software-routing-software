## Что именно сделать

### 1. Таблица активных соединений → `DataTable`

Сейчас вкладка «Соединения» рисует таблицу вручную (`TableContainer`/`Paper`/`Table`/`TableHead`/
`TableBody`/`TableRow`/`TableCell`). Замени на `DataTable` с теми же колонками и тем же
содержимым ячеек:
`["Протокол", "Источник", "Назначение", "Правило", "Выход", "Трафик", "Состояние", "Действие"]`.
Содержимое ячеек, форматтеры `address`/`bytes`, кнопка `Закрыть` с проверкой роли и
`ConfirmDialog` — сохранить как есть.

Обрати внимание: `DataTable` подставляет «—» вместо `null`/`undefined`. Если ячейка сейчас
рендерит `address(...)` (который сам даёт «—»), оставь вызов как есть — поведение не должно
измениться.

### 2. Фильтры и поиск → примитивы

- Вкладка «Соединения»: `<TextField label="Поиск соединений">` → `Field` с той же подписью;
  `<FormControl><InputLabel>Протокол</InputLabel><Select>…<MenuItem>` → `SelectField`
  с `label="Протокол"` и тем же списком значений (первый вариант — `Все`).
- Вкладка «Журнал»: селект «Уровень» и селект «Источник» → `SelectField` с теми же подписями,
  тем же порядком значений и теми же русскими подписями (`Отладка`, `Информация`,
  `Предупреждения`, `Ошибки`, `Все`); `<TextField label="Поиск в журнале">` → `Field`.
- Раскладку фильтров держи существующей группой (`.diag-controls` из `styles.css` уже
  предназначен именно для этого: см. комментарий там) вместо `Stack`. Кнопки
  (`Обновить`, `Пауза`/`Продолжить`, `Копировать`, `Скачать`, `Очистить`) не трогай.

### 3. Обёртки → существующие классы

- `<Stack>`/`<Box sx={{...}}>` для раскладки замени на `div` с существующими классами
  (`page`, `diag-controls`) или на `PageSection`. Цвета/отступы — только через `theme.ts`
  токены и существующие классы; никаких хексов и инлайновых `style`.
- `<Box component="pre" sx={{…}}>` просмотрщика журнала: сам `<pre>` оставь, но если он
  требует цвет/фон — используй токены (`tokens`) как сейчас либо существующий класс; не
  вводи новых CSS-алиасов.

### 4. После правки в файле не должно остаться ни одного запрещённого импорта

В идеале из `@mui/material` остаются только `Button` и `Typography` (и, если
понадобится, `Alert`). Проверь себя той же проверкой:

```
python3 - <<'PY'
import re
s=open('src/pages/Diagnostics.tsx',encoding='utf-8').read()
names=[n.strip() for m in re.finditer(r'import\s*\{([^}]*)\}\s*from\s*"@mui/material"',s,re.S) for n in m.group(1).split(',') if n.strip()]
allowed={'Alert','Button','Checkbox','Dialog','DialogActions','DialogContent','DialogTitle','FormControlLabel','Switch','Typography'}
print([n for n in names if n not in allowed])
PY
```
Должен напечатать `[]`.

  запросы (`api.runtimeEngine`/`runtimeConnections`/`runtimeLogs`, `close.mutate`),

- Не менять контракт API, типы, backend.
- Не добавлять зависимости и новые компоненты-примитивы. Не трогать другие страницы.
- Никаких хардкод-hex, инлайновых стилей цвета, эмодзи.
- Не коммить.
