# Задание (шаг 2): широкая таблица правил firewall не должна ломать слова на узком экране

Репозиторий: `/home/poshl9k/GitHub/software-routing-software`.
Контекст: только что список правил firewall в `frontend/src/pages/Firewall.tsx` получил
9 явных колонок (`№, Имя, Действие, Протокол, Откуда, Куда, Порт, Состояние, Действия`).
Гейт зелёный, но визуальная проверка на узком окне выявила дефект.

## Дефект (подтверждён скриншотом)

`frontend/src/theme.ts` задаёт всем ячейкам таблиц `overflowWrap: "anywhere"` и
`wordBreak: "break-word"`. Когда таблице не хватает ширины (окно ~900 px, рабочая область
≥651 px — это поддержанный «desktop»-диапазон, см. брейкпоинт drawer в `App.tsx`),
браузер начинает рвать слова по слогам и даже по буквам: заголовки превращаются в
`ДЕЙСТВ / ИЕ`, `ПРО / ТОК / ОЛ`, ячейки — в `block_ / wan_rd / p`, `Включ / ено · / журна / л`.
Таблица не прокручивается, а сплющивается.

## Что сделать

1. В `frontend/src/pages/Firewall.tsx` обернуть ТОЛЬКО таблицу правил зоны (`DataTable`
   с колонками `№ … Действия`, внутри карточки `Правила зоны ${tab}`) в
   `<div className="table-wide">…</div>`. Никакие другие таблицы на странице не трогать.
2. В `frontend/src/styles.css` добавить (в разделе, где живут табличные правила, рядом с
   комментарием про `.MuiTableCell-root .MuiFormControl-root`):

```css
/* Wide multi-column tables (firewall rules) scroll horizontally instead of
   squeezing cells until words break per character on narrow windows. */
.table-wide table {
  min-width: 1040px;
}
```

MUI `TableContainer` уже имеет `overflow-x: auto`, поэтому при нехватке ширины таблица
будет прокручиваться, а не ломаться по буквам. Никаких inline-стилей, никаких хексов.
