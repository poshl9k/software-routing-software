## Что сделать

Композер правила сейчас — резидентная `Card` внутри карточки зоны. Перенеси его в модальное окно:

- `Dialog` (`fullWidth`, `maxWidth="md"`) → `DialogTitle` `Правило: <имя || «Новое правило»>`
  → `DialogContent` с существующим `FormGrid` (все поля те же: `Имя`, `Откуда`, `Куда`,
  `Протокол`, `Порт / @алиас`, `Действие`, `Позиция`, `Включено`, `Записывать совпадения`)
  → существующий `EditorFooter` в конце (окно закрывается как `Отмена`).
- `Добавить правило` создаёт строку и сразу открывает окно (как сейчас `setComposerIndex`).
- `Изменить` в строке открывает окно для этого правила.
- `DeleteButton` остаётся и в строке списка, и в окне (существующее поведение удаления через
  `setZoneRules`, `setComposerIndex(null)`).
- Секции внутри окна: `Идентификация` (`Имя`, `Включено`), `Условие` (`Откуда`, `Куда`,
  `Протокол`, `Порт / @алиас`), `Решение` (`Действие`, `Позиция`, `Записывать совпадения`) —
  существующие контролы и валидаторы без изменений. Существующий `InfoNote` про порядок
  проверки оставить внутри окна.
- Список правил зоны остаётся как есть (таблица с `№ … Действия`, пустое состояние
