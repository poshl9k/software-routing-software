## Что сделать

1. Редактор исключения — модальное окно: `Dialog` `fullWidth maxWidth="md"` → `DialogTitle`
   (`Исключение: <имя || «Новое исключение»>`, справа `DeleteButton` с существующим
   `Удалить исключение …`) → `DialogContent` с `FormGrid` и секциями
   `Идентификация` (`Имя исключения`), `Условие` (`Источник IP (bypass)`, `Порты (bypass)`,
   `Протокол (bypass)`) → существующий `EditorFooter` в конце.
2. `+ Добавить исключение` создаёт строку и сразу открывает окно (как сейчас `updateBypass`).
3. Клик `Изменить` в строке списка исключений открывает окно для этой строки. Пока исключений
   нет — строку-подсказку/пустое состояние не выдумывать: сохранить текущий вид (пустой список
   исключений — нормальное состояние, отдельная строка-подсказка не требуется, но если сейчас
   есть текст — не удалять).
4. **Убрать значок удаления, висящий отдельной строкой** в потоке страницы под секцией
   «Исключения» (на снимке он виден отдельной иконкой — это `DeleteButton` инлайн-строки,
   который при переносе в окно должен уйти в заголовок окна, а не остаться на странице).
5. Секция «Обновление списков (после запуска TProxy)» — это настройка уровня страницы, её
   оставить на странице как есть (не переносить в окно).

`portsValid` и т.п.), `patch`, порядок строк, `save`, вкладки `Простой`/`Эксперт`, таблицы и
