## Что именно сделать (два пункта)

### 1. Пустое состояние у read-only таблиц «Входящие сайты» и DDNS

Сейчас, когда список пуст, `Collection` для сайтов и DDNS рисует `DataTable` без `empty` →
пользователь видит безликое «Нет записей», хотя кнопка добавления есть в шапке карточки.
Передай в этот `DataTable` конкретный текст по `kind`:
- `sites` → `Сайтов нет. Добавьте сайт.`
- `ddns` → `Доменов DDNS нет. Добавьте домен.`

Туннельная ветка (со своим `EmptyState title="Туннелей пока нет"`) не меняется.

### 2. Честная оговорка про состояние сертификата у сайтов

Колонка «Статус» у сайтов сейчас всегда показывает `Статус недоступен`: живое состояние
сертификата панель не читает, и это честно — выдумывать его запрещено. Но повторять одну
строку в каждой строке таблицы без объяснения — шум.

Рядом с блоком сайтов добавь такой же пояснительный абзац `<p className="sub">`, какой уже
есть у DDNS (строка ~1178: `Статус DDNS агент пока не отдаёт через HTTP API; результат последней…`).
Формулировка для сайтов, по смыслу:
`Состояние сертификата на устройстве панель пока не читает: колонка «Статус» показывает только известное ей — выпуск произойдёт при применении.`
Один абзац, один раз. Саму колонку и её значения НЕ меняй, вторых сообщений не добавляй.
