## Рабочие процессы

1. Импорт одиночного/нескольких sing-box выходов: открыть `/singbox/new`, вставить ссылки, после импорта попасть в `/?tab=singbox` (`frontend/src/routes/singbox/new/+page.svelte:11-35`). В редакторе tag обязателен; переименование и изменение параметров — разные вызовы (`frontend/src/routes/singbox/[tag]/+page.svelte:79-107`). Экспорт share link и проверки доступны отдельно (`:179`; `frontend/src/lib/api/clientSingbox.ts:188-269`).
2. Мастер импорта (`frontend/src/lib/components/subscriptions/AddTunnelWizard.svelte:305-315,548-579`): сначала тип «один сервер» (ссылки/часть JSON/TOML → `api.singboxImportLinks`, `:318-345`), «группа серверов» (inline), «подписка по URL» либо файл; для URL/file последовательно форма URL+заголовки/путь → загрузка предпросмотра и выбор узлов (исключение по key) → создание (`:351-440,548-579`). Ошибки: пустой файл «Файл «{name}» пуст», нет URL «Укажите URL подписки», нет пути «Укажите путь к файлу» (`frontend/messages/ru.json:2186,2193-2194`; `.../AddTunnelWizard.svelte:285-301,351-355`). Inline нельзя сохранить пустым (`.../AddTunnelWizard.svelte:401-414`). Затем задать label, headers, refreshHours, enabled, selector/urltest, regex-фильтры и bindInterface (`internal/singbox/subscription/types.go:62-93,148-176`; `internal/api/subscription_dto.go:90-119`); `preview`/`detect-headers` до записи (`frontend/src/lib/api/clientSubscriptions.ts:145-165`). Парсер распознаёт Clash YAML, sing-box/Xray/Mieru JSON, TrustTunnel TOML либо набор ссылок (включая нормализацию тела) (`internal/singbox/subscription/service.go:1762-1776`). Fetch проверяет публичность URL, запрещённые заголовки, ограничивает ответ 5 MiB и время 20 с (`internal/singbox/subscription/fetch.go:15-28,42-50,92-127`); refresh вычисляет diff, хранит rejected/orphan/excluded (`internal/singbox/subscription/service.go:509-526,829-854`). Можно выбрать активного члена, исключить/вернуть/добавить вручную, группировать подписки (`frontend/src/lib/api/clientSubscriptions.ts:68-197`). Обновление вручную `/refresh`; планировщик каждую минуту проверяет enabled URL-подписки с `refreshHours>0`, не запускает наложенные refresh; inline и file автоматически НЕ обновляются (`internal/singbox/subscription/store.go:577-593`; `internal/singbox/subscription/scheduler.go:19-101`). URL-test: `url`, `intervalSec`, `toleranceMs`, по умолчанию `https://www.gstatic.com/generate_204`/60 с/50 мс (`internal/singbox/subscription/types.go:25-57`); selector — ручной выбор, URL-test периодически перевыбирает самый быстрый узел (`:25-32`). `GET /active-now` берёт live-выбор из Clash (`internal/singbox/subscription/service.go:1986`; `internal/api/subscription_members.go:70-106`). Regex — Go RE2 без lookahead/lookbehind; сообщение UI «Похоже на некорректное выражение (окончательно проверит сервер)» (`frontend/messages/ru.json:2052-2053`).
3. Тесты: задержка конкретного туннеля — POST `/tunnels/delay-check?tag=`, `DelayChecker.CheckOne` (`internal/api/singbox.go:288-307`); в списке connectivity/latency обогащаются историей Clash proxy (`:540-560`). Проверки connectivity, внешнего IP и SSE speed-stream — отдельные операции, последний выдаёт этапы download/upload и события interval/result/done/error (`:837-1109`). Тест прокси группы — `/router/proxies/test` (`internal/server/server_routes.go:979-982`); он не равен загрузке подписки и не доказывает доступность каждого удалённого сервера.
4. Первичная настройка Router в ПУСТОМ состоянии: выбрать туннель → сервисы из пресетов → «Включить» (`frontend/src/lib/components/sb-router/EmptyState.svelte:1-3,31-55,83-129`). `finishSetup` создаёт правила, заводит `dns-direct` и `dns-tunnel` с detour на выбранный туннель, синхронизирует доменные DNS-правила, ставит `route.final=direct`, `deviceMode=all`, WAN autodetect, sniff=true, переключает режим на `tproxy` (`frontend/src/lib/components/sb-router/emptyStateActions.ts:21-75,146-205`). Это реальный router quickstart; название `quickstart` в именах файлов не требуется. Русские метки: `sb_router_empty_step_tunnel` «Туннель», `sb_router_empty_step_services` «Что в туннель», `sb_router_empty_enable_hint` «sing-box будет настроен на весь роутер. Дополнительные настройки движка — в режиме «Эксперт».» (`frontend/messages/ru.json:5529-5538`).
5. Последующее добавление правила: кнопка на `/routing?tab=singbox&add=1` (`frontend/src/lib/components/sb-router/addWizardStore.ts:37-49,86-114`); шаг 1 «Что направить» — пресет/список, шаг 2 «Куда направить» — туннель(и), direct либо block, шаг 3 предпросмотр → сохранить или «добавить ещё» (`.../AddWizardPanel.svelte:81-93,148-218,248-390`; `frontend/messages/ru.json:5315,5318,5358`). Нельзя сохранить без матчера либо без выбранного выхода/туннеля (`.../AddWizardPanel.svelte:81-93`); мастер делает запросы через `submitWizard`, в простом режиме синхронизирует DNS (`:136-199`; `.../addWizardActions.ts:1`). Расширенное управление: reorder/bulk, редактирование rule-set/detour, DNS, inspect и staging (`frontend/src/lib/api/clientSbRouter.ts:69-171,236-447`).
6. Связь со смежными моделями: `Preset` — повторно используемый сервисный шаблон DNS/sing-box/HydraRoute, а не установленный маршрут (`internal/presets/types.go:12-55`); каталог маршрутов объединяет managed/system/WAN интерфейсы (`internal/routing/catalog.go:17-69,268-337`); `StaticRouteList` содержит tunnelID, subnets, fallback `reject` (kill-switch), enabled; сервис реагирует на старт/стоп/удаление туннеля и восстанавливается при запуске (`internal/storage/staticroute.go:13-23`; `internal/staticroute/service.go:10-26`). Прокси-инстансы имеют отдельные intent/status/phase и реестр выходов (`internal/proxyrt/types.go:13-118`; `internal/proxyrt/exitreg/registry.go:143-286`); не считать их синонимом outbound sing-box.

## Пробелы относительно нашей панели (только функциональный паритет)

Наш контракт уже содержит `TProxyRule` с matcher domain/IP/source/port/rule_sets, action direct/block/route, `final`, DNS servers/rules, `ProxyOutbound`, `ProxyGroup`, `ProxySubscription`, `RuleSetSource` (`backend/src/vs_router/schema.py:274-312,339-410,422-519`). Поэтому их наличие само по себе НЕ пробел. В сравнении с awg-manager остаются:
