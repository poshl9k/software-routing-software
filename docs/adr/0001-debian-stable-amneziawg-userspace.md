# ADR-0001: Платформа MVP — Debian stable, AmneziaWG в userspace

**Status:** accepted
**Date:** 2026-09-26
**Deciders:** владелец проекта + агент (сессия grill-with-docs)

## Context

План разработки (router_project_plan.md v0.2) требует закрепить дистрибутив и режим работы AmneziaWG до начала реализации. AmneziaWG существует в двух режимах: out-of-tree kernel-модуль (быстрее, но требует пересборки/DKMS при каждом обновлении ядра) и userspace-порт `amneziawg-go` (работает на любом ядре, медленнее). Дистрибутив должен иметь актуальный Kea с управляющим API, Caddy (включая L4-модуль), systemd-networkd и предсказуемые обновления.

## Decision

1. Основной дистрибутив MVP — **Debian 13 (stable)**: пакеты из репозитория, версии фиксируются.
2. **Ubuntu** — второй поддерживаемый дистрибутив; рассматривается сразу после стабилизации MVP как самый популярный вариант для пользователей.
3. **AmneziaWG в MVP — userspace-порт (`amneziawg-go`)**; kernel-модуль — возможная оптимизация после MVP.

## Rationale

- Debian stable даёт фиксируемые версии пакетов, минимум неожиданностей и долгий горизонт поддержки — приоритет MVP над свежестью.
- Userspace-AmneziaWG снимает зависимость от сборки модуля под каждое ядро: обновление ядра не ломает туннели. Для целевой нагрузки (дом/prosumer/малый офис) просадка производительности userspace некритична.
- Ubuntu отложен намеренно: поддержка второго дистрибутива до стабилизации MVP удваивает матрицу проверок. Популярность Ubuntu делает его логичным следующим шагом, но не первым.

## Consequences

- Лабораторные проверки этапа 0 проводятся на Debian 13: Kea ctrl-agent API, стабильность amneziawg-go (параметры обфускации, совместимость профилей, поведение после обновления ядра), Caddy L4 TLS passthrough.
- Если Kea/Caddy в Debian stable окажутся слишком старыми — отдельное решение: официальный репозиторий ISC/Caddy против смены кандидата.
- Поддержка Ubuntu в MVP не обещается; установщик проектируется так, чтобы добавление второго дистрибутива не требовал изменения архитектуры (детектор дистрибутива + фиксированные пути systemd units).
