# ADR-0008: Самодостаточный установочный образ и онлайн-обновление по выпуску

**Статус:** принят
**Дата:** 2026-10-05
**Участники:** владелец продукта и Hermes Agent

## Контекст

Сейчас ISO не содержит кода: `late_command` в preseed клонирует репозиторий с
GitHub и делает `git checkout @VS_ROUTER_REVISION@`. Это создаёт две проблемы.
Во-первых, установка невоспроизводима без сети и без опубликованного коммита:
если коммит не запушен (реальный случай на этой сессии), `late_command` падает,
`installer-prepare.sh` не выполняется, firstboot-сервис не включается — система
остаётся без bootstrap и **без какого-либо сигнала об ошибке**. Во-вторых,
идентичность продукта отсутствует: `version="0.1.0"` захардкожен, а `update.sh`
выполняет `git pull --ff-only`, то есть «обновление» = текущая ветка, что прямо
противоречит ADR-0005 («не из ветки и не `latest`»). ADR-0005 принял загрузку
зафиксированных версий из сети и отложил полностью автономный ISO «на отдельное
обсуждение».

## Решение

Установочный ISO становится **самодостаточным**: он несёт исходники
зафиксированного выпуска (commit id + контрольная сумма), распаковываемые
локально на этапе установки, без сетевого клонирования. Выпуск идентифицируется
парой **commit id + semver**, записываемой при установке в
`/etc/vs-router/version.json` и отдаваемой read-only через `GET /api/release`
(отдельно от `GET /api/versions` — конфигурационных версий). После установки
панель **предлагает онлайн-обновление** до более нового проверенного выпуска —
только после сверки текущего выпуска и явного согласия. `update.sh` переводит
систему на зафиксированный выпуск, а не на ветку.

В языке: **«выпуск установки»** — продукт (commit+semver); **«версия»** в UI
панели всегда означает **версию конфигурации**.

## Рассмотренные варианты

- **Оставить сетевой клон (ADR-0005):** проще и меньше образ, но установка
  зависит от сети и от публикации коммита, а провал молчит. Отвергнуто — именно
  этот путь дал наблюдаемый сбой.
- **Самодостаточный ISO (принято):** воспроизводимо, работает офлайн, сбой
  установки виден локально. Увеличивает образ на дерево исходников (без истории
  git — она многократно больше и не нужна).
- **Lab-хук локального git (`VS_ROUTER_TEST_GIT_URL`):** уже существует, но это
  испытательная оснастка, а не продуктовый путь.

Это частично отменяет отложенность автономного ISO в ADR-0005 и оставляет в силе
его главное: версии фиксированы и проверяемы, `latest`/ветка не используются.

## Последствия

- Сборка ISO вкладывает исходники зафиксированного коммита и их SHA-256;
  установка распаковывает локально и проверяет целостность. Провал установки
  становится обнаружимым (маркер незавершённой установки + причина на локальную
  консоль + явный повтор), а не молчаливым.
- Появляется первоклассное понятие «выпуск установки»: идентификатор, эндпоинт,
  отображение в панели, проверка перед обновлением.
- Обновление — только явное, до проверенного выпуска; автообновление и `git pull`
  ветки запрещены.
- Образ растёт; историю git в него не кладём.
