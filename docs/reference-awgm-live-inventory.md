# AWG Manager: функциональная инвентаризация живой панели

## Кратко: что важно для sing-box

На доступной без входа панели AWGM 2.19.9 sing-box установлен и работает. Маршрутизация — отдельный раздел `/routing?tab=singbox`: простой режим показывает цепочку «источник → движок → первый подходящий маршрут → direct/туннель», системные правила sniff, перехвата DNS, приватных адресов и UDP timeout, пользовательские правила с сортировкой/редактированием/удалением; экспертный режим показывает таблицу правил, rule-sets, outbounds, DNS-серверы и DNS-правила, rewrite и inbounds. Видны `first-match`, `final=direct`, `urltest`, `selector`, удалённые/inline rule-sets, DNS `final`, `strategy`, DNS detour через VPN, `redirect` и `tproxy` inbounds. Текущий FakeIP выключен: его редактор не отображается. На главной есть отдельные списки AWG, sing-box туннелей, подписок и WG endpoints. Присутствуют мастер создания одиночного сервера/группы/подписки и экран импорта sing-box share-link; существующая подписка позволяет выбирать сервер, URL-test, обновлять, исключать участников и менять URL/заголовки/фильтры. В настройках есть Bootstrap-DNS, локальный Clash API, NDMS Proxy для sing-box, уровни логов. Это наблюдения экранов, а не проверка успешного сохранения/запуска; записи в панель не вносились. [D04,D05,S03,L19,L02]
